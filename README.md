# SOUP Tools website

The home page, privacy policy and terms of [SOUP Tools](https://github.com/zachleolewis/SOUP-Tools-Releases), published with
GitHub Pages at **https://zachleolewis.github.io/soup-tools/**.

- [`index.html`](index.html): what SOUP Tools and the Drive Sync extension are
- [`privacy.html`](privacy.html): what SOUP and Drive Sync do with your data (and Google user data)
- [`terms.html`](terms.html): terms of use

Plain HTML, no build step: a push to `main` publishes it. Maintainer notes: [`CLAUDE.md`](CLAUDE.md).
